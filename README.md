# StudioWARP
StudioWARP - программа, для настройки и проверки работы самой программы CloudFlareWARP. 
В программу входит такие функции как: ВКЛ/ВЫКЛ WARP, выбор протокола и конфиг для WARP, диагностика когда включен WARP и во время включения WARP.

Программа сделана в целях: удобство для настройки самой программы, чтобы не лазить в командную строку; проверять и изучить проблему, по которой не включается WARP, чтобы эту данную проблему решить.
Также в программу входит другие функции, как: измерение пинга, проверку блокировки сайтов, который WARP успешно обходит, утечки IP/DNS, проверка SSL на утечки и т.п.

ВНИМАНИЕ! данная программа находится на ALPHA тестирование и пока-что не сильно пригодна для полного использования. Но те кто хотят испробовать и хотят поделиться идеями, а также поискать баги, то я буду рад.

ТРЕБОВАНИЕ: Python 1.11+ 1.12+ Зависимости/библиотеки сами должны будут скачаться, но если что, будет залит какие зависимости нужно будет скачать.
